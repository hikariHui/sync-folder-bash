# sync-folder

将文件夹 A 的内容同步到文件夹 B，核心目标是**减少跨硬盘读写消耗**。

## 工作原理

同步分四个阶段：

1. **扫描**：递归扫描 A 和 B，记录每个文件的相对路径和大小
2. **比对**：以相对路径为坐标，生成待新增、待删除的候选列表
3. **移动识别**：在候选新增和候选删除之间，按文件名+大小匹配，识别出 B 内部可以直接 `mv` 的文件（零跨盘消耗）
4. **展示计划 → 用户确认 → 执行**

### 文件相同判断

文件名（basename）+ 文件大小相同，视为同一文件。不比较文件内容。

### 删除行为

不实际删除，而是将文件移动到 `B/_trash_YYYYMMDD_HHMMSS/` 目录下（保留原始目录结构），由用户自行决定是否清理。

### 执行顺序

`B 内部移动` → `移到回收站` → `从 A 复制` ，最大限度减少中间状态冲突。

---

## 系统要求

- Rust 1.70+（用于编译）
- macOS 或 Linux

---

## 编译

```bash
cargo build --release
```

编译产物位于 `target/release/sync-folder`，可复制到任意位置使用。

---

## 使用方法

```bash
./target/release/sync-folder /path/to/A /path/to/B
```

运行后会展示操作计划，输入 `y` 确认执行，`n` 取消。

## 已知限制

- **移动识别为贪心匹配**：若 B 中有多个文件同名同大小，只有一个会被识别为移动，其余进入 trash
- **不处理符号链接**：`find` 只扫描普通文件
- **大小相同内容不同的文件视为已同步**：极少数情况下可能漏同步（如文件被原地替换但大小恰好相同）
- **不会清理 B 中的空目录**：删除文件后原目录如变为空，需手动清理
